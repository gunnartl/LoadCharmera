# Charmera Import (web page for iPhone)

One file, `index.html`. Everything runs on the phone; nothing is uploaded.

## Put it on GitHub Pages
1. On github.com: **New repository** (public), e.g. `charmera`.
2. **Add file -> Upload files**, upload `index.html`, **Commit changes**.
3. **Settings -> Pages**: Source "Deploy from a branch", branch `main`, folder `/ (root)`, **Save**.
4. After a minute the page is at `https://<your-username>.github.io/charmera/`.

## Use (iPhone, Safari)
1. Connect the camera by USB-C and open the page.
2. **Choose files from the camera** -> Choose Files -> Browse -> CR1KX_DATA -> DCIM -> Select -> Open.
3. Tap the ones you want, **Rotate** any that are sideways, pick the noise filter, **Convert**.
4. **Save to Photos** and choose "Save Items" in the share sheet.

Tip: Share -> Add to Home Screen makes it open like an app.
